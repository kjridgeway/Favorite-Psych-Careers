# HTML & CSS – Weeks 1–3

## About This Project

This repository showcases my progress throughout Weeks 1–3 of my Web Development course. During these first few weeks, I have been learning the foundations of website development using **HTML and CSS**.

The projects and assignments included here demonstrate my understanding of webpage structure, styling, formatting, and basic design principles as I continue developing my skills.

## What I've Learned

### HTML (HyperText Markup Language)
- Creating the basic structure of an HTML document.
- Using headings, paragraphs, lists, and links.
- Adding images and organizing webpage content.
- Using HTML elements, tags, and attributes.
- Creating structured and readable webpages.
- Connecting external CSS stylesheets to HTML documents.

### CSS (Cascading Style Sheets)
- Applying colors, fonts, and text formatting.
- Using background colors and images.
- Adjusting margins, padding, and spacing.
- Styling borders, rounded corners, and containers.
- Working with classes and element selectors.
- Using pseudo-classes such as `:hover`, `:active`, and `:visited`.
- Improving webpage appearance and readability.
